# 네이버 클립 URL 변환기 설치 및 사용 안내

경기일보 플랫폼운영지원부 남건우 · 1.0.0.0 version

## 처음 설치

1. 배포 ZIP을 풀고 `naver-clip-url-converter` 폴더를 보관합니다.

   **설치한 폴더는 계속 보관해 주세요.** 확장프로그램이 해당 폴더에서 파일을 읽습니다.

2. 일반 Chrome 창 주소창에 `chrome://extensions/`를 입력합니다.
3. 개발자 모드를 켜고 **압축해제된 확장 프로그램 로드**를 누릅니다.
4. `manifest.json`이 들어 있는 폴더를 선택합니다.
5. 필요한 사이트 접근을 허용하고, 퍼즐 메뉴에서 변환기 아이콘을 고정합니다.

> **참고 · 기존 설치본 업데이트**
>
> 기존 설치 폴더에 새 파일을 덮어쓴 뒤 변환기 카드의 **둥근 화살표**를 누릅니다.
> 업데이트 전에 입력한 주소는 다시 입력해 주세요.

## 사용 방법

1. 네이버 클립 영상에서 **공유 → HTML복사**를 누릅니다.
2. 변환기에 복사한 내용을 붙여넣고 **URL 추출 및 복사**를 누릅니다.
3. 복사 완료 알림에서 **확인**을 누릅니다.
4. WCMS 기사작성기의 **편집도구 → 동영상**을 엽니다.
5. URL 입력란에 붙여넣고, 영상 미리보기를 확인한 뒤 **가져오기**를 누릅니다.

크기는 필요할 때만 기존 작성기의 설정에서 조정합니다.
기사작성기가 별도 창으로 열려도 지원 대상 주소라면 호환 기능이 자동 적용됩니다.

## 입력을 확인할 수 없을 때

- 공유 링크 확인에 실패하면 해당 영상의 **HTML복사** 내용을 사용합니다.
- 영상 코드는 한 개씩 입력합니다.
- 자동 복사가 실패하면 표시된 주소를 `Ctrl+C`로 복사합니다.
- WCMS 호환 기능은 코드에 지정된 도메인과 작성기 구조에서 동작합니다.
